# 标签系统使用说明（考公 / 行测）

> 学习者使用**个人考点树**（`userId = 本人`，`isSystem = false`）。  
> 官方行测树（`shared/src/tag-data/gongkao.ts`）是**导入模板**，不是所有人共用的只读树。  
> 题库侧仍可用全局系统标签；学习端打标/筛选/统计只认个人树。

---

## 1. 标签是干什么的

标签 = **考点坐标系**。作用不是「好看分类」，而是：

1. 拍照识题后，把错题钉到具体考点  
2. 错题本按考点筛选、复习  
3. 统计页做薄弱点诊断  
4. 薄弱点专项练习 / 题库按考点抽题  

没有标签，错题只是一堆散题；有了标签，才能「知道弱在哪 → 针对练」。

---

## 2. 个人考点树长什么样

三层（可自行增删改，最多约 4 层）：

```
言语理解          ← 模块（根）
  └ 逻辑填空      ← 一级考点
       └ 实词辨析  ← 二级考点（叶子，真正打到题上的多为这一层）
```

五大模块模板：言语理解、判断推理、数量关系、资料分析、常识判断。

- 模板定义：`shared/src/tag-data/gongkao.ts`  
- 学习端导入：Web「考点管理」→ **导入官方模板**（`POST /api/tags/import-template`）  
- 每人一份副本；改自己的树不影响别人，也不改官方模板文件  

---

## 3. 你怎么用（学习者 / Web）

### 3.1 首次：导入模板

1. 打开 Web → **考点管理**（`/tags`）  
2. 若提示尚未导入，点「导入官方模板」  
3. 导入后可改名、增删节点、在根下加自定义模块  

### 3.2 拍错题 → 打标

1. 识别题干后，从**你的个人树**里选考点（不能自由发明主标签名）  
2. 保存前可在校对页改标签  
3. 保存后错题通过 `ErrorItem.tags` 关联到个人节点  

### 3.3 按考点找错题

错题列表筛选：模块 → 一级考点 → 二级考点。  
后端用 `tagId` + 子树匹配（选模块会包含其下所有挂题）。

### 3.4 看薄弱点

「统计」页按 `ErrorItem.tags`（M2M）聚合次数，**不再**读旧的 `knowledgePoints` JSON。  
未打标题目会计入「未打标」。

---

## 4. API 摘要（学习端）

| 接口 | 说明 |
|------|------|
| `GET /api/tags` | 本人树；`needsImport`；`?flat=true` 叶子名列表 |
| `POST /api/tags` | 新建节点 `{ name, parentId? }` |
| `PATCH /api/tags/[id]` | 改名 / 移父 |
| `DELETE /api/tags?id=` | 删节点（含子树，解绑题目） |
| `POST /api/tags/import-template` | 从官方考公树导入（仅空树时） |
| `GET /api/tags/stats` | 按个人标签使用次数 |
| `GET /api/error-items/list?tagId=` | 按节点含子树筛错题 |

---

## 5. 和「错题本 / 科目」的关系

- 错题本仍是**本子分组**（可建多个）  
- **标签**是跨本子的考点体系；诊断和筛选优先认个人树节点  
- 笔记本与标签共存：本子管「放哪」，标签管「考什么」  

---

## 6. 常见问题

**Q：统计里出现陌生标签名？**  
A：旧版曾按 `knowledgePoints` 字符串统计。现已改为只统计已关联的个人标签；请重新打标或忽略历史脏名。

**Q：筛选是「叶子」还是「文件夹」？**  
A：列表筛选用节点 id + 子树。叶子 pill 一般是无子节点的名字；点模块也会筛到其下所有挂题。

**Q：可以完全自定义树吗？**  
A：可以。导入模板只是起点；可增删改。主标签仍须来自你的树，不能随意填新字符串当主考点。

**Q：改官方模板定义改哪里？**  
A：改 `shared/src/tag-data/gongkao.ts`。已导入用户不会自动同步；新用户导入才拿到新版。

**Q：题库标签呢？**  
A：题库仍可走全局 / 系统考点；与学习端个人树分离，后续可做名称映射。

---

## 7. 推荐日常流程

**导入模板 → 按需改树 → 拍题确认考点 → 定期看薄弱点 → 对最弱考点专项练。**

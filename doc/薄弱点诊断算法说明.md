# 薄弱点诊断算法说明

> 适用版本:v1.9.1+　　代码位置:`src/lib/diagnosis.ts`、`src/lib/elo.ts`、`GET /api/diagnosis/weakness`
> 本文面向想了解"系统凭什么说我这里薄弱"的用户与后续维护者。

---

## 1. 一句话版本

> **你最近反复错、还没掌握的知识点,就是你的薄弱点。** 系统把每道错题和每次练习折算成带权重的"失败证据",按知识点聚合后打 0~100 的虚弱分,排名输出。

---

## 2. 证据从哪来

| 证据 | 来源 | 说明 |
| :--- | :--- | :--- |
| 错题 | 拍照录入 / 练习答错自动入本 | 每道错题由 AI 打上知识点标签(如"削弱论证") |
| 练习记录 | 专项练习 / 举一反三 | 带 `tagId` 归因,答错记为最新失败证据,答对记为"正在掌握" |

练习答错的题会**自动收进错题本**并携带来源标注,所以两条证据链最终汇合到同一套知识点体系上。

---

## 3. 单条证据的权重:新鲜度 × 掌握程度

每条证据不是一票一票平等计数的,而是先折算成"失败质量"(failMass):

```
证据权重 = 时间衰减 × 掌握度权重
```

### 3.1 时间衰减(半衰期 45 天)

```
w = 0.5^(距今天数 / 45)
```

- 今天的错题权重 1.0
- 45 天前的错题权重 0.5
- 90 天前的错题权重 0.25

**含义**:三个月前错的题,远不如昨天错的题能说明"你现在薄弱"。

### 3.2 掌握度权重

| 掌握状态 | 权重 | 含义 |
| :--- | :--- | :--- |
| 未掌握 | 1.0 | 完整计入薄弱证据 |
| 复习中 | 0.6 | 部分计入 |
| 已掌握 | 0.2 | 基本出仓——错过但已学会,不再代表现在的短板 |

---

## 4. 三个通道合成虚弱分(0~100)

对每个知识点桶,三个信号加权求和:

```
虚弱分 = 100 × ( 0.6 × 失败质量
              + 0.2 × 复发度
              + 0.2 × 未掌握占比 )
```

| 通道 | 权重 | 计算方式 | 直觉 |
| :--- | :--- | :--- | :--- |
| 失败质量 | 0.6 | 该点 failMass ÷ 全部知识点中的最大 failMass | "错得最多最重" |
| 复发度 | 0.2 | 出现过的自然周数 ÷ 3(3 周封顶) | "反反复复一直错" |
| 未掌握占比 | 0.2 | (未掌握 + 0.5×复习中) ÷ 总题数 | "还没学会的比例" |

**设计意图**:失败质量是主信号;复发度抓"长期反复"的顽疾;未掌握占比抓"存量没消化"。一道错题命中多个同义标签时只计一次,防止虚胖。

### 同义考点归并

AI 打标可能写出"削弱论证"和"削弱论证题"两种写法。同名(归一化后)的标签会聚合到同一个**主标签桶**,证据合并计算,避免同一弱点被拆成两行稀释排名。

---

## 5. 两个辅助信号

### 5.1 置信度

```
置信度 = min(1, 失败质量 ÷ 3.5)
```

证据越少越不可信——只有 1 道错题的知识点,排名再高也只应参考。统计页会按置信度弱化低证据点的展示。

### 5.2 趋势

比较**近 30 天**与**之前 60 天**的加权失败质量:

- 近期 ÷ 之前 > 1.2 → **恶化中**(越错越多)
- 近期 ÷ 之前 < 0.7 → **改善中**(快拿下了)
- 其余 → 持平;只在近期有、之前没有 → 新出现的恶化点

---

## 6. 练习如何实时影响诊断

- **答错**:立刻生成一条满权重的最新失败证据,该知识点虚弱分上升——这就是"练错一题,诊断马上变重"的原因
- **答对**:按"已掌握"权重(0.2)计为正面证据,同时计入练习正确率

### Elo 能力值(练习难度自适应)

专项练习的难度由**用户 × 知识点**维度的 Elo 分数驱动:

```
难度基准:easy=1000 / medium=1200 / hard=1400 / harder=1500
预期正确率 = 1 / (1 + 10^((难度分 − 能力分)/400))
能力更新:R' = R + 32 × (结果 − 预期)
```

- 答对超出能力的题涨得多,答错简单的题掉得多
- 能力值由练习历史**确定性回放**得出,不落库,永远可重算、可回溯
- 连续答对 → 难度上调;连续答错 → 下调,保证出的题始终"够得着又不太容易"

---

## 7. 数据流全景

```
拍照录入 ──AI 打标──▶ 错题(知识点标签)
专项练习 ──答错──▶ 自动入错题本(带 origin 来源标注)
专项练习 ──每题──▶ 练习记录(tagId 归因)
                          │
                          ▼
        GET /api/diagnosis/weakness
        ① 同义标签归并 → 知识点桶
        ② 逐条证据折算 时间衰减 × 掌握度
        ③ 三通道合成虚弱分 + 置信度 + 趋势
        ④ 按章节(标签树)分组输出排名
                          │
                          ▼
        统计页「薄弱点诊断」→ 点「专项练习」定向出题 → 答错再入本
```

闭环:**录错题 → 诊断 → 定向练习 → 练错再入本**,练习越多,诊断越准。

---

## 8. 已知边界

- 长期不录入错题、不做练习,诊断结果会整体衰减(所有点分数趋近),排名仍有效但参考价值下降——保持录入习惯即可
- 标签质量依赖 AI 打标,同义归并只能合并同名写法;发现明显打错的标签可在错题详情手动修正
- 考试前突击录入大量旧题时,旧题权重已被时间衰减压低,诊断会优先反映新错的内容

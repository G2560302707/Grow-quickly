# 目录结构说明

> 仓库为 **npm workspaces 单仓多端**结构：根目录是学习端（Next.js），`admin/` 是管理端（Next.js），`shared/` 是两端共享包（`@grow/shared`），`uniapp/` 是独立的多端（H5/小程序）应用。
> 相关文档：[技术文档](技术文档.md)、[部署文档](部署文档.md)、[功能文档](功能文档.md)

```
Grow quickly/
├─ package.json                 # 根 = 学习端；workspaces: ["shared", "admin"]
├─ next.config.ts               # 学习端 Next 配置（output: standalone、transpilePackages: ["@grow/shared"]）
├─ Dockerfile                   # 学习端生产镜像（多阶段构建 + entrypoint 初始化）

├─ docker-compose.build.yml     # 部署 override：学习端改为本地构建（不拉 ghcr 预构建镜像）
├─ docker-compose.https.yml     # 内置 HTTPS 部署变体（镜像内 443 反代 + 自签名证书）
```

## 几条阅读线索

- **找某个功能的后端接口**：`src/app/api/<模块>/route.ts`（学习端）或 `admin/src/app/api/`（管理端）。
- **找某个页面**：学习端 `src/app/<路径>/page.tsx`；管理端 `admin/src/app/(dash)/`；uniapp `uniapp/src/pages/`。
- **改数据模型**：`prisma/schema.prisma` → `npx prisma migrate dev`（三端共用，改完两端都要能跑）。
- **两端共用的逻辑放哪**：`shared/src/`；只属于学习域的（ELO、薄弱点诊断、智能出题等）留在 `src/lib/`。

## 一、学习端 Web（http://<host>:3000）

### 1. 录入错题（首页「上传新题」）

| 功能 | 说明 |
|---|---|
| 拍照 / 图片上传 | 支持拍照或选择图片；自动压缩（>1MB 时压到 ≤1MB） |
| 整页题目定位 | 上传整页试卷后 AI 自动框出每道题（虚线题号框），**点框即录该题**；双栏排版已适配 |
| 自由框选裁剪 | 无题号或定位失败时自动回退为手动拖拽裁剪，裁完识别 |
| 同图连续录题 | 保存成功后可对同一张原图继续框选下一题，整页错题逐题录入不重复拍照 |
| 识别与校对 | AI 识别题干（含表格转录、LaTeX 公式）、正确答案、我的答案、错因、知识点标签，校对编辑器中人工修正后再保存 |
| AI 解题 | 粘贴题目文本直接求解（无需图片） |
| 直接录入 | 手动填写题目/答案/解析，不经过 AI |

### 2. 错题本管理

- 多错题本（按科目/模块），支持新建、重命名、删除；
- 错题列表多维度筛选：掌握状态、时间范围、知识点标签、年级学期、试卷等级、来源、关键字搜索；批量删除；
- 错题详情：查看原图与识别内容、维护个人笔记、修改掌握状态（未掌握/复习中/已掌握）、关联知识点标签；
- **GeoGebra 动态演示**：数学类题目可生成可交互的函数/几何演示（自动判断适用性）；
- **举一反三**：对单道错题生成同考点变式练习（难度 easy / medium / hard / harder）；
- 数据导入导出：个人数据一键备份（JSON），导入时合并去重；
- 打印预览：按筛选结果导出打印（可选是否含答案/解析/知识点、图片缩放）。

### 3. 练习

| 模式 | 入口 | 说明 |
|---|---|---|
| 自由练习 | 错题详情「举一反三」 | 对单题生成变式题，作答后记录 |
| 题库待做 | `/practice/pool` | 生成的练习题统一入库（待做/已做/已弃），支持恢复 |
| 薄弱点定向 | `/practice/smart` | 基于诊断报告自动挑最薄弱的知识点出题（可指定知识点与难度） |
| 作答记录 | `/practice/history` | 全部练习历史（渠道、难度、对错、回看解析） |

### 4. 统计中心（`/stats`）

- 学习概览：累计错题、掌握率、本周录入/活跃；
- 练习统计：模块正确率、难度分布、活跃趋势图；
- 渠道对比：自由练习 vs 巩固练习的效果对比；
- 薄弱点证据链：错误积累 → 标注知识点 → 诊断报告（`/api/diagnosis/weakness`，算法见链接文档）。

### 5. 专注刷卷（`/focus`，独立底部 Tab）

- 番茄钟专注计时；模考掐表（可自定义每模块用时）；
- 专注时长统计（今日/本周/连续天数/总时长）。

### 6. 账户与个人

- 注册 / 登录 / 改名改密（`/register`，注册开关由管理端控制）；
- 设置弹窗：语言（中/英）、账户、关于；
- 公告红点通知（管理员发布后提醒阅读）；
- 意见反馈提交（可附联系方式，管理端处理）；
- PWA：可添加到主屏幕，类原生体验。

## 二、uniapp 多端（H5：http://localhost:5173；小程序为规划阶段）

与学习端共用同一套后端接口与数据，功能与 Web 同构：

| 页面 | 功能 |
|---|---|
| 识别（analyze） | 拍照/相册识题：整页题目定位框选、自由裁剪、AI 识别、保存、同图连续录题 |
| 错题本（items） | 错题本与错题列表、筛选、详情 |
| 练习（practice/pool/history） | 举一反三、薄弱点定向出题、题库待做、练习记录 |
| 专注（focus） | 番茄钟、模考掐表、专注统计 |
| 统计（stats） | 学习概览、练习统计、薄弱点提示 |
| 我的（profile） | 概览数据、资料修改、数据导入导出、帮助、反馈 |

> **小程序（Phase 5）前置条件**：HTTPS + ICP 备案域名、微信内容安全合规（UGC/AIGC 检测）、隐私指引配置等，详见 [管理后台拆分方案 §5](管理后台拆分方案.md)；部署侧当前无需考虑。

## 三、管理端 Admin（http://<host>:3001，仅 admin 角色）

| 模块 | 功能 |
|---|---|
| 仪表盘 | 全站用户/错题/练习趋势统计 |
| 用户管理 | 用户列表、启用/禁用、删除、详情查看 |
| 公告管理 | 发布/下架/删除系统公告（学习端红点提醒） |
| 反馈处理 | 查看用户反馈、标记处理状态（可邮件通知） |
| 系统设置 | **AI 供应商/多实例管理**（Gemini / OpenAI 兼容 / Azure，保存即生效，支持连通性测试）、**Prompts 模板**（识别/出题/重解可自定义）、**邮件 SMTP**（反馈通知）、注册开关、AI 超时 |
| 系统工具 | Prompt 调试、知识点标签迁移重建、系统重置（危险操作区） |

安全约定：管理端建议只在内网/VPN/白名单暴露；会话与学习端互相隔离。

## 四、功能与部署的对应关系速查

| 想用这个功能 | 需要什么 |
|---|---|
| 录错题、笔记、掌握度、打印、导入导出 | 部署即可用（无外部依赖） |
| 拍照识题 / AI 解题 / 出题 / 薄弱点定向 | 管理端配置 AI 供应商（任一家，OpenAI 兼容接口即可，如 DeepSeek） |
| 反馈邮件通知 | 管理端配置 SMTP |
| 摄像头拍照 / PWA 安装 | 生产环境启用 HTTPS |
| 微信小程序 | 暂未开放（见 Phase 5 前置条件） |

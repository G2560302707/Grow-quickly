# UI 设计审计问题清单（Phase 0 产出）

> 日期：2026-10-17　|　方法：Playwright 登录态截图 17 页（存 `_scratch_design_audit/shots/`，不入库）逐页对比
> 结论先行：**整体骨架健康（白卡 + 大圆角 + 禁用态统一），但存在「两套主色、三种标题、两套选中态、三套图标、三种空状态」的碎片化**，距离"有产品感"差一层系统性。

---

## 一、整体印象

**好的方面（可复用的既有一致性）**
- 白色卡片 + 大圆角 + 浅灰蓝底的内容页骨架，全站统一 ✅
- 按钮禁用态（浅紫渐变 + 半透明白字）在 analyze/practice/help 三处完全一致 ✅
- 登录/注册页最接近「墨蓝靛金」品牌：深蓝底 + 金色小点缀 + 白卡表单，完成度最高 ✅
- focus 勋章区（金色 3dicons + 灰度锁定态）质感在线 ✅
- tab bar 四项图标 + 选中靛蓝，全站统一 ✅

**核心问题一句话**：金色只出现在首页头部/数据强调/勋章，而所有主 CTA 是蓝紫色——「墨蓝靛金」的品牌承诺在大多数页面没有兑现，更像"默认主题 + 局部鎏金"。

---

## 二、问题清单（按影响排序）

### P0 · 主色体系分裂（两套主色并存）
| 位置 | 现状 |
|---|---|
| 首页「+ 拍错题」 | **金色**按钮 |
| focus「开始专注」/ analyze「开始 AI 识别」/ login「登 录」/ data-manage「导出」/ profile-edit「保存修改」/ pool「去做」 | **蓝紫色**按钮（约 #5b67d8） |
| index/stats 数据强调（掌握率/答对率） | 金色数字 |

→ 同屏可能出现金 + 靛蓝两个"主色"，用户无法建立"金色 = 品牌动作"的认知。**需要定死：主 CTA 用哪套**（建议金色留给品牌/成就/庆祝，CTA 统一靛蓝；或反向，二选一全站执行）。

### P1 · 页面头部三套样式
1. 深色墨蓝头部 + 白字标题（index、focus、login/register、profile 头部）——无返回键
2. 白底黑字 + 黑返回箭头（items/detail/practice/tags/stats/help 等子页）
3. 白底但无标题仅返回箭头（部分页）

→ tab 页深、子页浅可以理解，但深浅交界生硬（index 深蓝头部下方直接白卡堆叠，过渡区被卡片割裂）。

### P1 · 章节标题三种写法
1. **蓝竖条 + 粗标题**（stats「错题掌握度」、help「快速上手」、data-manage「导出备份」）
2. 纯粗体文字（focus「今日目标」「专注徽章」、practice-history「待做题库」）
3. 大标题 + 右侧弱化计数（index「我的错题本 · 9 个」）

→ 同一种"卡片内分节标题"应有唯一组件。

### P1 · 筛选芯片（chip）选中态两种
- **实心蓝底白字**：items「全部」、help 反馈「功能建议」
- **描边蓝框白底**：history「全部」、pool「待做/全部」、focus 时长「25 分钟」
- **浅灰无描边**（未选中态倒是统一）

→ 同一语义（单选筛选）两套选中表达，混用时最伤一致性。

### P2 · 图标体系三套混用
1. index 错题本列表：**灰紫单色首字块**（你/3/2/1/其）——信息弱、与彩色模块卡不齐
2. index 学科模块：**彩色底 + 彩色线性 icon**（资料分析绿/言语理解蓝紫/判断推理紫）
3. profile 菜单：**淡蓝底双色线性 icon**
→ 三种"列表行图标"并存；首字块建议换统一素材或加底色系统（按学科配色）。

### P2 · 空状态三种、且无统一组件
- detail：红字错误条「请求失败（405）」——技术错误码直出，无重试、无返回引导（P3 顺带修：无参数进详情应给友好空态文案）
- record-detail：白卡居中「记录不存在」
- items/practice-history 底部：「— 没有更多了 —」文字
→ 缺插画/图形 + 统一文案口吻的 `<EmptyState>` 组件（配 3dicons 素材可复用勋章管线）。

### P2 · 数字排版
- 大数字（index 7、profile 66.7%、focus 0）字号/字重接近但未统一规格；无 `tabular-nums`，倒计时/统计未来会跳动。

### P3 · 细节
- stats 趋势图柱状图坐标轴/图例配色（答对蓝/未答浅蓝）与科目分布条颜色不成体系（红黄绿语义色仅 stats 用）。
- index 统计条「已掌握 0」绿色与 stats 三色语义条重复表达。
- profile 退出登录红描边按钮孤悬底部，与内容卡间距偏大，可并入设置组。

## 三、Phase 1 设计系统建议（承接清单）

1. **色板定稿**：`--brand-ink`（墨蓝）、`--brand-gold`（鎏金，限品牌/成就/庆祝/数据强调）、`--brand-primary`（靛蓝，全部 CTA/链接/选中态）+ 语义色（红黄绿仅 stats）。写入 `doc/设计规范.md`。
2. **唯一 chip 组件**：单选一律「选中=实心底白字」，未选中=浅灰。
3. **唯一节标题组件**（竖条式）+ 唯一页头组件（tab 深头 / 子页浅头两个变体）。
4. **EmptyState 组件**：icon（3dicons）+ 标题 + 副文案 + 可选动作，替换三处。
5. **数字统一** `font-variant-numeric: tabular-nums` + 字号阶梯。
6. index 错题本首字块 → 按模块色板着色或统一 3dicons。

> Phase 2 重构 4 核心页时按上表逐条落地；本清单作为验收 checklist。

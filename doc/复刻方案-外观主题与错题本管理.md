## 二、改动清单

### A. 后端（Next.js + Prisma）

1. **schema**：`Subject` 模型加两个字段
   ```prisma
   iconKey    String  @default("other") // 图标键，见 D 节图标表
   isDefault  Boolean @default(false)   // 默认本标记，每用户至多一个
   ```
   手工迁移（沿用 focus_daily_goal 的 migrate diff + deploy 流程，非交互环境已踩通）。
2. **存量数据迁移**（迁移 SQL 内完成，幂等）：每个用户若无 `isDefault=true` 的本，创建"其他"本（iconKey=other, isDefault=true）；无 iconKey 的旧本按名称映射默认图标（言语理解→yanyu 等，映射不到给 other）。
3. **`POST /api/notebooks`**：接受 `iconKey`（白名单校验，非法回退 other）；创建时若用户一个本都没有，自动设为默认本。
4. **`PUT /api/notebooks/[id]`**：支持改 `name` + `iconKey`；默认本不允许改名为其他名称外的名字？——不，按截图语义：默认本**可改名可换图标**，但**不可删除**、不可把别的本设为默认（截图无"设为默认"操作，保持最简）。
5. **`DELETE /api/notebooks/[id]`**：改逻辑——
   - 默认本：400「默认错题本不可删除」
   - 非默认本：将其 `errorItems` 的 `subjectId` 改指向用户默认本（用户无默认本则先自动创建），再删本（**替换**现在"有题拒绝删"的行为，与截图文案"删其它本时题目会迁入此处"一致）
   - 相关错误文案中文化
6. **stats 接口**：不动（首页概览已按 notebooks 合计）。

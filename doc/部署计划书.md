# 部署计划书：小程序上线 + 后端服务器部署

| 部分 | 产物 | 部署位置 |
|---|---|---|
| 后端 | Docker 镜像（Next.js standalone） | 云服务器（推荐 2C4G 起） |

关键链路：小程序 → HTTPS 域名（Nginx）→ 后端容器 :3000。

## 阶段一：准备条件（一次性）

1. **云服务器**：购买一台国内云服务器（阿里云/腾讯云，2C4G 起步），安装 Docker + Docker Compose。
2. **域名**：
   - 你的域名：**`after7lab.cloud`**，推荐子域名 **`after7lab.cloud`** 专用于后端。
   - 进行 **ICP 备案**（微信小程序强制要求备案域名，周期约 1~3 周，尽早启动）。
   - 备案通过后，DNS 添加 A 记录：`api` → 服务器公网 IP。
3. **HTTPS 证书**：微信小程序 `request` 合法域名必须是 `https://`。可用云厂商免费证书（有效期 3 个月，需续期）或 Let's Encrypt（certbot 自动续期）。
4. **微信公众平台**（mp.weixin.qq.com，使用 appid `wx571724ac4670bcd7` 对应账号）：
   - 「开发管理 → 开发设置」获取 **AppSecret**，填到后端 `.env` 的 `WECHAT_APP_SECRET`。
   - 「开发管理 → 开发设置 → 服务器域名 → request 合法域名」添加：`https://after7lab.cloud`。
   - 若小程序包含照相/相册（拍照识别错题），确认相关权限声明；类目需符合「教育」类要求。

## 阶段二：后端部署到服务器

### 1. 修改小程序端 API 地址

`uniapp/src/utils/config.ts:14` 当前是局域网调试地址，上线前改为：

```ts
baseUrl = "https://after7lab.cloud";
```

### 2. 准备生产环境变量

在服务器上创建 `.env`（参考 `.env.example`）：

```env
DATABASE_URL="file:/app/data/dev.db"
NEXTAUTH_SECRET="<openssl rand -base64 32 生成>"
AUTH_TRUST_HOST=true
AI_PROVIDER="gemini"        # 或 openai
GOOGLE_API_KEY="<生产密钥>"
WECHAT_APPID="wx571724ac4670bcd7"
WECHAT_APP_SECRET="<微信公众平台获取>"
LOG_LEVEL="info"
```

> AI 密钥也可不进环境变量，通过管理后台 UI 首次运行时配置（`config/app-config.json`，挂载卷持久化）。

### 3. 构建并运行容器

```bash
# 本地构建镜像并推送到公司 GitLab 镜像仓库（或服务器上直接 build）
docker build -t registry.公司gitlab.com/团队/ai-errorbook:latest .
docker push registry.公司gitlab.com/团队/ai-errorbook:latest

# 服务器 docker-compose.yml
services:
  app:
    image: registry.公司gitlab.com/团队/ai-errorbook:latest
    restart: unless-stopped
    ports: ["127.0.0.1:3000:3000"]
    env_file: .env
    volumes:
      - app-data:/app/data        # SQLite 数据库，必须持久化
      - app-config:/app/config    # AI 密钥配置
volumes:
  app-data:
  app-config:
```

> 注：镜像内已有 `docker-entrypoint.sh` 完成 migrate/seed，首次启动会自动初始化数据库和管理员账号。

### 4. Nginx 反向代理 + HTTPS

> **本机 80 端口不可用**，小程序 HTTPS 只需 443，因此这里**去掉 80 跳转，只监听 443**（网络层只需放行 443/TCP；80 是否可达不影响小程序真机请求）。

```nginx
server {
    listen 443 ssl;
    http2 on;
    server_name after7lab.cloud;
    ssl_certificate     /etc/letsencrypt/live/after7lab.cloud/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/after7lab.cloud/privkey.pem;

    client_max_body_size 20m;   # 错题拍照上传

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;   # AI 分析接口耗时较长
    }
}
```

**关于证书申请**（80 不可用时仍可签发 Let's Encrypt 证书）：

```bash
# 方式A：DNS 校验（无需 80 端口，推荐）
certbot certonly --nginx -d after7lab.cloud --preferred-challenges http  # 需 80
# 改用 DNS-01 校验，在 DNS 服务商加 TXT 记录：
certbot certonly --manual -d after7lab.cloud --preferred-challenges dns \
    --cert-name after7lab.cloud

# 方式B：直接申请云厂商免费证书（域名已备案，若支持则无 80 依赖）
# 下载证书后替换上面 ssl_certificate 路径即可
```

> 80 不可用的两个常见原因：① 服务器上 80 已被其他 Web 服务占用，需停用或换端口；② 云厂商安全组/open 端口未放行。因为域名已备案、小程序走 443，**非必须解决**——只需确保 443/TCP 在外网可达。

### 5. 验证

## 阶段三：小程序构建与上传

### 1. 编译 mp-weixin 产物

两种方式任选：

- **HBuilderX（推荐，图形化）**：导入 `uniapp` 目录 → 发行 → 小程序-微信 → 输出 `dist/build/mp-weixin`。
- **CLI**：在 `uniapp` 目录 `npm run build:mp-weixin`（若无此脚本需先在 `package.json` 添加）。

### 2. 微信开发者工具

1. 下载微信开发者工具，导入构建产物目录（appid 已是 `wx571724ac4670bcd7`）。
2. 「详情 → 本地设置」确认不勾选「不校验合法域名」（上线前必须校验通过）。
3. 真机预览：手机扫码，完整走通 登录（wx.login）→ 拍照识别 → 练习 流程。

### 3. 上传与发布

1. 工具内点「上传」，填写版本号（如 1.0.0）和备注。
2. 微信公众平台 → 版本管理 → 提交审核（首次审核约 1~7 天，教育类需类目资质）。
3. 审核通过后「发布」，小程序全量上线。
4. 之后迭代：改代码 → 重新 build → 上传 → 提交审核 → 发布。

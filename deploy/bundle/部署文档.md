# 📦 服务器部署文档（照着做就行）

> 本文件夹 `bundle/` 包含部署所需的全部文件。
> 服务器要求：Docker + Docker Compose 已装好、Nginx 已装好、域名已备案（80 不可用）。

## 一、需要上传的文件（共 6 个）

```
bundle/
  wrong-notebook.tar          后端服务镜像（153MB）→ 小程序/Web 的 API
  wrong-notebook-admin.tar    管理后台镜像（136MB）
  web-h5.tar.gz               Web 端 H5 静态站（170K）
  docker-compose.yml          容器编排
  .env.prod                   环境变量模板（需改）
  after7lab.conf              Nginx 配置（复制到服务器）
```

上传整个 `bundle/` 到服务器，例如放到 `/opt/app`。

---

## 二、放到服务器上执行（3 步）

### 第 1 步：加载镜像、解压 Web

```bash
cd /opt/app/bundle
docker load -i wrong-notebook.tar
docker load -i wrong-notebook-admin.tar
mkdir -p /opt/app/web && tar -xzf web-h5.tar.gz -C /opt/app/web
docker images   # 应看到 wrong-notebook:local 和 wrong-notebook-admin:local
```

### 第 2 步：配置环境变量并启动容器

```bash
cd /opt/app/bundle
cp .env.prod .env
vim .env      # 必改 3 处：NEXTAUTH_SECRET、WECHAT_APP_SECRET、GOOGLE_API_KEY
docker compose up -d
docker compose ps    # 两个容器都应为 running
```

> 生成密钥：`openssl rand -base64 32`（给 NEXTAUTH_SECRET）
> 首次启动自动建库、建管理员账号、补系统标签，SQLite 存在 `/opt/app/bundle/data`。

### 第 3 步：Nginx 配置 + DNS + 证书

**复制 `after7lab.conf` 到 Nginx 配置目录**（Ubuntu/Debian）：
```bash
sudo cp after7lab.conf /etc/nginx/sites-available/after7lab.cloud
# 启用：
sudo ln -s /etc/nginx/sites-available/after7lab.cloud /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```
> CentOS/RHEL：把 `after7lab.conf` 放到 `/etc/nginx/conf.d/` 即可。

**证书**：申请覆盖 `after7lab.cloud` 主域的证书（单域名证书即可，只有一个 server 块），
把 `after7lab.conf` 里的这两行改成你的实际路径：
```
ssl_certificate     /etc/letsencrypt/live/你的域名/fullchain.pem;
ssl_certificate_key /etc/letsencrypt/live/你的域名/privkey.pem;
```

**DNS**：添加一条 A 记录 `@` → 服务器公网 IP。

**安全组/防火墙**：放行 **443/TCP**（80 不用管）。

## 三、验证部署成功

```bash
curl -k https://after7lab.cloud/api/register/status   # 后端 API，应返回 JSON
curl -k https://after7lab.cloud/                      # Web 首页
curl -k https://after7lab.cloud/admin/login               # 管理后台登录页
```

打开管理后台登录 → 立即改默认管理员密码 → 在「系统设置」配置 AI 密钥。

## 四、给小程序用（Web/小程序二选一即可上线）

小程序已配置 appid `wx571724ac4670bcd7`，后端已就绪。上线前：
- 微信公众平台 → request 合法域名加 `https://after7lab.cloud`
- 确认 AppSecret 与 `bundle/.env` 的 `WECHAT_APP_SECRET` 一致

## 五、日常运维

| 事项 | 命令 |
|---|---|
| 看日志 | `docker compose -f /opt/app/bundle/docker-compose.yml logs -f` |
| 重启 | `docker compose -f /opt/app/bundle/docker-compose.yml restart` |
| 更新镜像 | 重新 `docker load` 新 tar，然后 `docker compose up -d`（SQLite 数据保留） |
| 备份数据库 | `cp /opt/app/bundle/data/dev.db /backup/dev-$(date +%F).db`（建议加到每日 cron） |
| 改 .env | `vim .env` 后 `docker compose up -d` 重建生效 |

## 常见问题
- **443 访问不通**：安全组/防火墙没放行 443；或 DNS 未生效。
- **微信报 domain 不合法**：request 域名没加 / 没备案 / 用了 http。
- **AI 无响应**：`.env` 的 GOOGLE_API_KEY 空，或统一走管理后台系统设置配置。
